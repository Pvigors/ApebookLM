## 正式发帖前

从最熟悉的一个社区开始，用该社区对应草稿，说明自己是作者，附上导览、仓库和具体反馈问题。这里的帖子和邀约均为草稿，没有自动发送或代表任何平台背书。

GitHub Social Preview 需要在仓库 Settings → Social preview 上传封面。GitHub 容器镜像首次发布后还需将三个包设为 Public 并匿名拉取验证，才能宣传免登录拉取。

## 完整生成体验版

静态导览与完整应用相互独立。完整生成体验版上线前需确定独立域名/服务器、模型预算、访客数据隔离和清理周期。目前的本地免密入口限定精确回环地址，不适合直接打开到公网；现有三个专用体验账号也不适合多人共享私人资料。

推荐先用只读交互导览展示界面，面向首批用户提供自托管指引。等独立体验环境确定后，再提供每人隔离、限额且定期清理的生成试用。
